# Pragmatic Engineering

Use evidence, explicit constraints, short feedback loops, and reversible decisions to improve engineering outcomes without unnecessary ceremony.

## Workflow

1. For engineering judgment and ownership, read [mindset and ownership](references/mindset-and-ownership.md).
2. Before committing to a solution, read [discovery and requirements](references/discovery-and-requirements.md).
3. For incremental execution and feedback, read [delivery and feedback](references/delivery-and-feedback.md).
4. During investigation, read [tools and debugging](references/tools-and-debugging.md).
5. For decoupling and change strategy, read [adaptability and reversibility](references/adaptability-and-reversibility.md).
6. For shared delivery and production responsibility, read [teams and operations](references/teams-and-operations.md).

Read only references relevant to the current task. Match effort to risk, state trade-offs explicitly, and prefer options that preserve future choices.
